# TỔNG QUAN DỰ ÁN WHAT2EAT

## 1. Giới thiệu dự án

**What2Eat** là website khám phá quán ăn và quản lý nhật ký ẩm thực cá nhân, giúp người dùng giải quyết câu hỏi: _“Hôm nay ăn gì?”_

Hệ thống kết hợp 3 chức năng chính:

- **Food Discovery:** Tìm kiếm, khám phá và gợi ý quán ăn.
- **Food Journal:** Ghi chép, đánh giá và lưu lại trải nghiệm ăn uống.
- **Social Food Planning:** Tạo nhóm, đề xuất và bình chọn quán ăn cùng bạn bè.

## 2. Chức năng chính

### Đối với người dùng

- Đăng ký, đăng nhập và quản lý tài khoản.
- Tìm kiếm, lọc và khám phá quán ăn theo nhu cầu.
- Gợi ý món ăn/quán ăn ngẫu nhiên.
- Xem chi tiết quán, đánh giá và lưu yêu thích.
- Tạo, chỉnh sửa và chia sẻ Food Note (nhật ký ẩm thực).
- Tạo nhóm Food Plan và bình chọn địa điểm ăn uống.
- Theo dõi thống kê chi tiêu và thói quen ăn uống cá nhân.

### Đối với quản trị viên

- Quản lý thông tin quán ăn và danh mục.
- Quản lý tài khoản người dùng.
- Kiểm duyệt nội dung Food Note công khai.
- Theo dõi hoạt động và thống kê hệ thống.

## 3. Định hướng giao diện

Website được thiết kế theo phong cách hiện đại, tối giản, thân thiện và tập trung vào trải nghiệm khám phá ẩm thực.

**Màu sắc chủ đạo:** Nâu – Vàng – Kem.

Giao diện cần:

- Dễ sử dụng, trực quan, không rối mắt.
- Tương thích máy tính, tablet và điện thoại.
- Có bản sắc riêng, không sao chép các nền tảng giao đồ ăn hiện có.

## 4. Công nghệ sử dụng

| Thành phần                 | Công nghệ                          |
| -------------------------- | ---------------------------------- |
| Frontend                   | HTML5, CSS3, JavaScript, Bootstrap |
| Biểu đồ                    | Chart.js                           |
| Backend                    | PHP 8.x, REST API                  |
| Database                   | MySQL 8.0                          |
| Định dạng trao đổi dữ liệu | JSON                               |

## 5. Định hướng triển khai

Dự án được phát triển theo từng giai đoạn:

1. Phân tích yêu cầu và thiết kế hệ thống.
2. Xây dựng cấu trúc giao diện và Design System.
3. Phát triển các trang giao diện chính.
4. Xây dựng chức năng người dùng.
5. Phát triển trang quản trị.
6. Kết nối PHP API và MySQL.
7. Kiểm thử chức năng, giao diện và khả năng tương thích trên thiết bị.

## 6. Mục tiêu sản phẩm

What2Eat hướng đến một nền tảng ẩm thực cá nhân hóa, không chỉ giúp người dùng tìm được địa điểm ăn uống phù hợp mà còn lưu giữ trải nghiệm và hỗ trợ lên kế hoạch ăn uống cùng bạn bè.

**Giá trị cốt lõi:**

_Khám phá món ngon – Tìm quán phù hợp – Lưu giữ trải nghiệm – Kết nối bạn bè._

\*_Thông điệp chính: “Hôm nay ăn gì? Để What2Eat giúp bạn tìm câu trả lời.”_
